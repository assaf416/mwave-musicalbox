## How to Use Presets

### Loading a Preset
1. Open the MWAVE FM-1 web emulator
2. Look at the right control panel
3. Click the "⭐ PRESETS" dropdown at the top
4. Select a preset from the grouped list:
   - 🎺 Mellotron Presets
   - 🎹 Organ Presets
   - 🎼 Piano Presets
   - ⚡ Electric Piano Presets
5. The preset info box displays the name, artist, and description
6. All synthesizer parameters instantly update to the preset values

### Understanding Preset Parameters

**Master Volume**: 0-100% - Overall output level
**Reverb**: 0-100% - Ambient space and echo effect
**Decay Time**: 0.1-2.0s - How long notes sustain after release

**Filter**: 0-100% - Lowpass filter cutoff frequency
**Resonance**: 0-100% - Lowpass filter Q/emphasis

**Attack**: 0-100% - Fade-in time for note start
**Sustain**: 0-100% - Level during note hold
**Release**: 0-100% - Fade-out time after note release

**Vibrato/Tremolo**: 0-100% - Modulation effects (pitch and amplitude)
**Chorus/Phaser**: 0-100% - Spatial effects
**Delay**: 0-100% - Echo and repetition effect
**LFO Rate/Amount**: 0-100% - Modulation speed and depth

## Preset Design Philosophy

Each preset captures the **essential character** of the referenced song:

- **Mellotron presets** emphasize warm, sustained tones with moderate reverb for orchestral richness
- **Organ presets** vary dramatically:
  - Hard rock (Deep Purple): High volume, tight reverb, fast attack
  - Classical (ELP): Moderate settings for clarity and power
  - Experimental (Pink Floyd): Extended reverb and effects for ambient soundscapes
- **Piano/E-Piano presets**: Moderate settings with warm filtering for natural tone

## Customization

Feel free to adjust any parameter while a preset is loaded. The preset acts as a starting point - you can:
- Increase/decrease volume for different dynamics
- Add more reverb for spacier sounds
- Adjust filter to brighten or darken the tone
- Modify attack/release for different articulation

Your custom settings remain active until you load a different preset.

## Technical Details

Presets are stored in `emulator/web/presets.json` as a JSON array with the following structure:

```json
{
  "id": "unique_preset_id",
  "name": "Preset Name",
  "artist": "Artist Name",
  "instrument": "Mellotron|Organ|Piano|Electric Piano",
  "description": "Description of the preset",
  "settings": {
    "masterVolume": 75,
    "reverb": 65,
    "decayTime": 1.2,
    "waveform": "sine|triangle|square|sawtooth",
    "knobs": {
      "cc20_filter": 70,
      "cc21_resonance": 40,
      "cc22_attack": 20,
      ... (CC23-CC35)
    },
    "faders": [0, 0, 0, 0, 0, 0, 0, 0]
  }
}
```

## Adding New Presets

To add your own presets:

1. Edit `emulator/web/presets.json`
2. Add a new preset object with:
   - Unique `id` (e.g., `organ_my_sound`)
   - `name`: Display name
   - `artist`: Your name or reference
   - `instrument`: Target instrument type
   - `description`: What the preset captures
   - `settings`: All parameter values (0-100)
3. The UI automatically loads and displays new presets
